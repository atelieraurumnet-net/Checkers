# Checkers

シンプルなチェッカーゲームです。

## 実行方法

1. このフォルダでローカルサーバーを起動します。
   ```bash
   python3 -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開きます。

## 操作

- 交互に駒を選んで、合法手をクリックします。
- 取れる手がある場合は、その手を優先して行う必要があります。
- 端まで進むとキングになり、後ろにも動けるようになります。

## ルール

- 盤面は 8x8 です。
- `黒` と `赤` が交互に手を進めます。
- 通常の駒は前方のみ進み、キングは前後両方に進めます。
- ジャンプで相手の駒を取れます。
- 連続ジャンプが可能な場合は、継続して飛び越えられます。
